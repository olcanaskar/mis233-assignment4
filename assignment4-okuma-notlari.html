Destructuring nedir?

En basit benzetme: bir kutunun içindekileri tek tek isimlendirerek dışarı almak.

Normalde:

const film = films[0]
const title = film.title
const year = film.year

Destructuring ile:

const { title, year } = films[0]

İki ana tür var:

  • Dizi: sıraya göre alır. const [first, second] = list
  • Nesne: isme göre alır. const { title, year } = film

Üç küçük parça daha:

  • Rest (...others): kalanı topla.
  • Spread (...list): içindekileri aç. Aynı üç nokta, zıt iş.
  • Default (= 0): değer yoksa yedeği kullan.

Önemli: Dizi destructuring aslında “value[0] oku” demek değil. Değerin Symbol.iterator metodunu çağırıp next() ile değerleri almak demek. Bu yüzden string, Set, Map ve generator da çalışır; düz nesne çalışmaz.

12 form

Aşağıdaki her kart bir form. Telefonda dokunup açabilirsin.

Form 1 — Değerleri sırayla al const [x, y] = f()

Syntax: const [oldest, newest] = yearRange(films)

Example: yearRange en eski ve en yeni film yılını döndürür.

Output: form 1: 1971 2026

Use it when: fonksiyon birden çok değeri sabit sırayla döndürüyorsa.

Watch out: Sıra tek bağlantıdır. Eksik eleman undefined olur. TS'de : [number, number] yazmazsak pozisyonlar number | undefined olur.

Form 2 — Birini atla, kalanı topla const [, second, ...others]

Syntax: const [, second, ...others] = ranked

Example: Rating'e göre sırala; ilkini atla; ikinciyi ve kalanları al.

Output: form 2: Tokyo Godfathers + 8 more

Use it when: ilk eleman ilgini çekmiyorsa.

Watch out: Virgül önemli. [second, ...others] ilk filmi second'a koyar. TS'de second Film | undefined olabilir.

Form 3 — İki değişkeni takas et [a, b] = [b, a]

Syntax: [firstPick, secondPick] = [secondPick, firstPick]

Output: form 3: Primetime <-> Tokyo Godfathers

Use it when: iki değer yer değiştirecekse.

Watch out: let kullan; const olmaz. Satır başına ; koy: ;[a, b] = [b, a]. TS'de önce dizinin ilk iki elemanı var mı kontrol ettik.

Form 4 — Dizide varsayılan değer const [a = 1] = []

Syntax: const [firstYear = 2003, secondYear = 2026] = emptyYears

Output: form 4: 2003 2026

Use it when: eleman eksik olabilir ve bir yedek varsa.

Watch out: Default sadece undefined için çalışır; null için çalışmaz.

Form 5 — İsme göre al const { a, b } = t

Syntax: const { title, year } = filmAt(0)

Output: form 5: Tokyo Godfathers 2003

Use it when: property adları istediğin değişken adlarıyla aynıysa.

Watch out: Yazım hatası JS'de undefined verir. Değer undefined veya null ise satır TypeError atar.

Form 6 — Alırken yeniden adlandır const { a: alpha } = t

Syntax: const { title: filmTitle, year: releaseYear } = filmAt(1)

Output: form 6: Primetime 2026

Use it when: property adı başka bir değişkenle çakışıyorsa veya daha net bir ad gerekiyorsa.

Watch out: Soldaki property, sağdaki yeni değişken. Sonrasında title veya year diye bir değişken yok. TS'de { title: string } bir tip değil, rename'dir.

Form 7 — Nesnede varsayılan const { a = 1 } = t

Syntax: const { rating = 0 } = unrated

Output: form 7: 0

Use it when: alan opsiyonel ve bir yedek istiyorsan.

Watch out: null default'u tetiklemez. { rating: null } varsa sonuç null olur.

Form 8 — Nesnede rest const { id, ...others } = t

Syntax: const { id, ...filmWithoutId } = filmAt(3)

Output: form 8: the-worst-person-in-the-world title,year,director,genres,rating

Use it when: bir alanı ayırıp kalanını saklayacaksan.

Watch out: Rest en sonda olmalı. Kopya sığdır; iç içe nesneler paylaşılır. React'te ({ title, children, ...rest }) bunun aynısıdır.

Form 9 — İç içe pattern const { p: { x }, list: [first] } = t

Syntax: const { director: { name: directorName }, genres: [mainGenre] } = filmAt(2)

Output: form 9: Bong Joon-ho crime

Use it when: nesnenin derin bir parçası veya içindeki dizinin ilk elemanı gerekiyorsa.

Watch out: Her seviye var olmalı; yoksa satır atar. mainGenre dizi boşsa undefined olabilir; TS bunu string | undefined yapar.

Form 10 — Hesaplanan key const { [key]: value } = t

Syntax: const key = 'year'; const { [key]: value } = filmAt(9)

Output: form 10: year 2019

Use it when: property adı çalışma anında seçiliyorsa.

Watch out: Köşeli parantez şart. TS'de düz string key TS2537 verir; literal veya keyof Film kullan.

Form 11 — Parametrede pattern function f({ a = 1 } = {})

Syntax: function createFilm({ title = 'Untitled', year = 0, rating = 0 } = {})

Output: form 11: { title: 'Waves', year: 2019, rating: 0 } ve form 11 empty: { title: 'Untitled', year: 0, rating: 0 }

Form 11b: form 11b: Tokyo Godfathers / Primetime

Use it when: fonksiyon bir options objesi alıyorsa ve çoğu alanın default'u varsa.

Watch out: = {} ayrı bir default. TS'de tip pattern'den sonra gelir. Zorunlu alanlar varsa = {} derlenmez. null defaults'u tetiklemez, hata atar.

Form 12 — Döngüde pattern for (const [k, v] of ...)

Syntax: for (const [id, film] of Object.entries(byId))

Output: form 12: tokyo-godfathers => Tokyo Godfathers ve form 12 map: Tokyo Godfathers 2003

Use it when: döngüde hem key hem value gerekiyorsa.

Watch out: Object.entries key'i string yapar. TS'de Map için [string, number] tuple tipi gerekir. for...in sadece key verir.

5 pitfall

1. undefined veya null'ı parçalamak TypeError 
const { title } = undefined

Output:

pitfall 1 undefined: TypeError - Cannot destructure property 'title' of 'undefined' as it is undefined.
pitfall 1 null: TypeError - Cannot destructure property 'title' of 'null' as it is null.

Why: undefined ve null property taşımaz; destructuring daha başlamadan atar.

2. Default null'ı değiştirmez sadece undefined 
const { rating = 5 } = { rating: null }

Output: pitfall 2: null (the default did not run)

Why: null bilinçli bir değerdir; default sadece undefined için çalışır.

3. Parantezsiz atama SyntaxError 
{ title } = film       // SyntaxError
({ title } = film)     // doğru

Output: pitfall 3: SyntaxError - Unexpected token '='

Why: Satır { ile başlarsa JavaScript bunu blok sanır. Parantez ifade bağlamına zorlar.

4. Sığ kopya nested obje paylaşılır 
const { director } = film
director.name = 'X'   // orijinal film de değişir

Output: pitfall 4: Someone Else (the original changed)

Why: Destructuring her property'nin değerini kopyalar. Nested obje için bu değer bir referanstır; iki değişken aynı objeyi gösterir.

5. Dizi sırası vs nesne sırası position vs name

Dizide sıra değişirse değerler de değişir. Nesnede property sırası değişse de isimler aynı olduğu için sonuç aynıdır.

Output: pitfall 5: Tokyo Godfathers Primetime | Primetime Tokyo Godfathers | Tokyo Godfathers Primetime

Why: Diziler pozisyona, nesneler isme göre okunur.

TypeScript konuları T1–T5

T1 — Pattern içindeki { a: string } tip değil, rename 
const { title: string } = filmAt(0)

Output: T1 rename: Tokyo Godfathers

Bu satır string adında bir değişken oluşturur; tip belirtmez. Doğru tip yazımı pattern'den sonra gelir:

const { title: filmTitle }: Film = filmAt(0)

Output: T1 typed: Tokyo Godfathers

T2 — Tuple ve as const 
const pair: [number, string] = [2003, 'Tokyo Godfathers']
const [pairYear, pairTitle] = pair

const years = [2003, 2026, 1997] as const
const [firstYear, secondYear] = years

Output: T2 tuple: 2003 Tokyo Godfathers ve T2 as const: 2003 2026

Tuple her pozisyonun tipini sabitler. as const ise diziyi readonly tuple ve literal tipler yapar. Tuple annotation olmadan pozisyonlar number | undefined olabilir.

T3 — noUncheckedIndexedAccess 
const [firstFilm] = films
console.log(firstFilm?.title)
if (!firstFilm) throw new Error('No first film')
console.log(firstFilm.title)

Output: T3 first: Tokyo Godfathers, T3 safe: Tokyo Godfathers, T3 default: Tokyo Godfathers

films[0] tipi Film | undefined. Doğrudan firstFilm.title yazarsan:

error TS18048: 'firstFilm' is possibly 'undefined'.

Çözüm: ?., if kontrolü veya default.

T4 — Opsiyonel alan ve default 
type OptionalRating = { rating?: number }
const rated: OptionalRating = { rating: 4.5 }
const { rating } = rated
const { rating: defaultRating = 0 } = rated
const empty: OptionalRating = {}
const { rating: emptyRating } = empty
const { rating: emptyDefault = 0 } = empty

Output: T4 optional: 4.5, T4 default: 4.5, T4 empty: undefined 0, T4 null: null

Opsiyonel alan number | undefined. Default undefined'ı kaldırır. rating?: number | null ise default sonrası null kalır.

T5 — Destructuring'in yol açtığı derleme hatası 
// @ts-expect-error - Type 'Film' is not assignable to type '{ rating: number; }'
const { rating: requiredRating }: { rating: number } = filmAt(0)

Hata:

error TS2322: Type 'Film' is not assignable to type '{ rating: number; }'.
  Types of property 'rating' are incompatible.
    Type 'number | undefined' is not assignable to type 'number'.
      Type 'undefined' is not assignable to type 'number'.

Düzeltme:

const { rating: safeRating = 0 }: { rating?: number } = filmAt(0)

Output: T5 suppressed: 4 ve T5 fixed: 4

@ts-expect-error sadece burada kullanıldı; assignment'ın izin verdiği tek suppression bu.

React: props ve children

Bir React bileşeni tek bir nesne alır: props. Etiketlerin arasına yazdığın içerik de bu nesnenin children alanıdır.

P1 — Props tek bir nesnedir

function FilmCardA(props) ve function FilmCardB({ film: { title }, children }) aynı şeyi yapar.

Output:

P1 A: <article><h2>Tokyo Godfathers</h2>same text</article>
P1 B: <article><h2>Tokyo Godfathers</h2>same text</article>

İkincisi form 11 (parametrede pattern), form 9 (nested film.title) ve form 5 (children) birleşimidir.

P2 — children sadece bir prop 
<FilmCardB film={filmAt(1)}>Primetime note</FilmCardB>
<FilmCardB film={filmAt(1)} children="Primetime note" />

Output:

P2 tag: <article><h2>Primetime</h2>Primetime note</article>
P2 prop: <article><h2>Primetime</h2>Primetime note</article>

İkisini birden verirsen JS'de etiket içeriği kazanır: P2 both: <article><h2>Primetime</h2>from tag</article>. TS bunu TS2710 ile reddeder: 'children' are specified twice.

P3 — Children ne olabilir?
  • String, number, element, birden çok element: render edilir.
  • undefined, null, false: hiçbir şey render etmez.
  • Fonksiyon: React uyarır ve hiçbir şey render etmez.

Örnek output: P3 string: "<article><h2>Tokyo Godfathers</h2>a review</article>" ve P3 undefined: "<article><h2>Tokyo Godfathers</h2></article>"

Fonksiyon için uyarı: Functions are not valid as a React child. ReactNode fonksiyonları içermez.

P4 — Children'ı diğer prop'lardan ayırma 
function FilmSection({ film, children, ...rest }) {
  return <section {...rest}><h2>{film.title}</h2>{children}</section>
}

Output: P4 rest: <section class="card" id="tokyo"><h2>Tokyo Godfathers</h2>text</section>

Spread sırası kazananı belirler: <section {...rest} className="explicit"> explicit'i tutar; <section className="explicit" {...rest}> rest'ten geleni tutar.

P5 — Props mu, children mı?

SlotCard header ve footer prop'ları alır; ChildrenCard sadece children alır.

Output:

P5 slots: <article><header><span>Header</span></header><h2>The Worst Person in the World</h2><footer><span>Footer</span></footer></article>
P5 children: <article><h2>The Worst Person in the World</h2><span>Header</span><span>Footer</span></article>

Layout sabitse ve her parçanın işi belliyse slot prop'ları kullan. İçeriği ve sırayı çağıran belirleyecekse children kullan.

P6 — Default, undefined ve null 
P6 default: <span>0</span>
P6 undefined: <span>0</span>
P6 null: <span>no rating</span>

undefined default'u tetikler; null tetiklemez. ?? ile null'ı ekranda no rating yaptık.

P7 — Props ve children tipleri
  • children?: ReactNode: string, number, element, dizi, null, undefined, false kabul eder; fonksiyon reddeder.
  • PropsWithChildren<{ film: Film }>: mevcut props tipine opsiyonel children ekler.
  • ComponentProps<'button'>: gerçek button prop'larını verir: type, disabled, onClick, children...

Output: P7 PropsWithChildren: <article><h2>Tokyo Godfathers</h2>child</article> ve P7 ComponentProps button: <button type="button" disabled="">Save</button>

Derleyicinin reddettikleri: yanlış film tipi (Type 'string' is not assignable to type 'Film'), bilinmeyen title prop'u, fonksiyon child (Type '() => string' is not assignable to type 'ReactNode'), variant prop'u.

key not: key normal prop değildir. props.key undefined olur; React onu bileşene vermeden önce ayırır. Output: P7 key probe: <span>undefined</span>.
